# Facebook Groups — Community-First Outreach

**Where to post:** South Florida soccer parent + coach Facebook groups
**Best time:** Sunday evening 6–9pm OR Monday morning 8–10am EST
**Frequency:** One group per day. Max 5 groups in week 1. Never cross-post identical content same day (algo flag + admin flag).

---

## Target groups (search Facebook for these)

Search these terms in Facebook search and join the active ones (groups with 500+ members and posts in the last 7 days):

- South Florida Youth Soccer
- Broward County Soccer Parents
- Miami-Dade Youth Soccer
- Palm Beach County Soccer Parents
- South Florida Soccer Coaches
- SFUYSA Parents / Coaches
- GHSL Soccer (Greater Hollywood Soccer League)
- [Your city] + soccer (e.g., "Plantation Soccer Parents," "Weston Soccer Community")

You'll usually find 5–10 active groups per county. Prioritize **coach-leaning groups** over parent-leaning ones — DOCs and assistant coaches are the buyers.

---

## Pre-post checklist for EACH group

- [ ] Apply to join (some require approval — apply 24–48 hrs before posting)
- [ ] Read the group rules. Some explicitly ban "promotional posts" — respect those.
- [ ] Engage with 1–2 other posts in the group BEFORE posting (comment, like). Don't post as a ghost account.
- [ ] Confirm your Facebook profile photo + cover photo look legit (no scammy red flags)

---

## Post content (copy-paste)

```
Hey all — finishing my MSBA at FAU this summer, and over the last year I've been building software for South Florida youth soccer clubs (specifically for DOCs and coaches running multi-team programs).

Honest question for any club admins, DOCs, or coaches in this group: what's the single most annoying part of running your club week-to-week? Coach drops, parent emails, scheduling, payments — whatever drives you crazy.

I've been talking to clubs for the last few weeks and want to make sure I'm building the right thing. Drop a comment or DM. If anyone wants to see what I've built so far, happy to send a 90-second demo.
```

**Why this version works:** it asks a real question, doesn't lead with the pitch, and offers the demo as a follow-up — not a hook. Groups punish "look at my thing" posts and reward "I'm asking for your input" posts.

---

## Follow-up plan

- Reply to every comment ASAP (within 30 min ideally)
- Anyone who comments with a real pain point → DM them: "Hey [name], saw your comment on [group]. Want to see how OffPitchOS handles that? 90-sec demo: https://youtu.be/ZylUkBkgqIs"
- Anyone who DMs first → send demo video, then offer the founding-club deal + Calendly: https://calendly.com/jozo-cancar27/offpitchos-demo
- If a group admin bans/removes your post → don't argue, find the next group

## Variations for different group types

### Coach-heavy group variant

```
Hey coaches — FAU MSBA student, finishing this summer. Spent the last year building a tool that handles the admin chaos for youth clubs (the Friday coach drops, the parent text storms, the schedule changes).

Curious — what's the one thing you wish your club's DOC would automate? Or, if you ARE the DOC: what's the single task that eats the most of your Friday afternoon?

Looking for South FL clubs to try it free. Happy to share a 90-second demo if anyone's curious.
```

### Parent-heavy group variant (lower priority — parents aren't buyers)

```
Hey soccer parents — quick poll. What's the worst part of your kid's soccer club's communication?

Building a tool for DOCs and coaches that's supposed to fix the parent-facing chaos (the last-minute schedule changes, the GroupMe pile-ups, the missed-practice mystery). Curious what would actually help YOU as a parent.

Drop a thought or DM. I'm an FAU grad student building this in South Florida.
```

---

## DO NOT

- Cross-post identical content to multiple groups same day (algo flag + admin flag — instant ban risk)
- Tag random users in the post
- Include `$` sign or "free" in body (spam filter triggers)
- Post a screenshot of your dashboard without context (looks like an ad)
- Include the Calendly link in the initial post — save it for DMs
- Argue with negative comments — just delete or ignore. Engagement on a negative comment boosts its reach in the group.

---

## What "good" looks like (realistic ranges)

For a 1,500-member SF soccer group, an on-topic community post should generate:
- 3–8 comments
- 10–25 likes
- 1–3 DMs

If you're getting 0 comments and 0 DMs across 3 groups → the post copy is broken or you're posting at the wrong time. Revisit.

If you're getting comments but no demos requested → people are engaging but the pitch isn't compelling. The fix is the COMMENT REPLIES, not the post.
