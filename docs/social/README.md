# OffPitchOS — Social Media Outreach Playbook

Drafts and channels for organic launch posts. Use these in order — LinkedIn first, Facebook second, Instagram third.

## When to use what

| File | Channel | Where to post | Priority | Time cost |
|---|---|---|---|---|
| [`linkedin.md`](./linkedin.md) | LinkedIn | linkedin.com (your profile) | **1** | 10 min |
| [`facebook-groups.md`](./facebook-groups.md) | Facebook | South FL soccer groups | **2** | 15 min per group |
| [`instagram-reel.md`](./instagram-reel.md) | Instagram | OffPitchOS IG account | **3** | 5 min upload |

## Order of operations

1. **Before any post:** update your LinkedIn profile per `linkedin.md` checklist (headline, bio, featured section, photo). A great post on a bare profile converts at zero.
2. **Day 1 (Tue or Wed AM):** post LinkedIn. Reply to every comment within 1 hour.
3. **Day 2:** wait. See what LinkedIn engagement looks like.
4. **Day 3–7:** one Facebook group post per day, max 5 groups in the first week. Don't cross-post identical content same day.
5. **Whenever:** Instagram Reel goes up. No time-sensitivity.

## Voice/style rules — non-negotiable

- Use "FAU MSBA student graduating this summer" — never "senior" (he's grad), never "undergrad."
- Never use emoji unless platform expects them (Instagram caption is the only exception in this folder).
- Never claim customer count, "47 clubs already using us" stats, or social proof you don't have. Zero customers = zero claims.
- Always include the 90-second demo link: https://youtu.be/ZylUkBkgqIs
- Always include the founding-club offer: "First 10 South FL clubs at 50% off forever."
- Always link to https://offpitchos.com (not the bare landing — the live app).
